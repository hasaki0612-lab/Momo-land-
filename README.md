# Momo Land

Momo Land 的玩家说明。这里介绍服务器里的常用指令、商店和日常玩法，忘记怎么用时来翻一下就好。

![Momo Land 空岛主城全景](assets/server-island.png)

*服务器实景，由服主提供。*

## 从这里开始

进服后输入 **`/menu`** 打开服务器面板。生存一区、生存二区、每日任务、签到和挂机池都能从这里进入。

想直接回自己的家，用 **`/home world`** 或 **`/home world_new`**。回主城用 **`/spawn`**。
