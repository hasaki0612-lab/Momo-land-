# 1.5.0 更新说明

本次增加公共 Warp，并调整成长与商店节奏：

- [公共 Warp](warp.md)：四个世界、每人每世界 2 个、12 个一页、收藏和安全检查；设置 500 金币、访客 60 金币。
- 创建者每日 Warp 收入上限 900 金币；达到上限后访客仍收费。访问自己的免费。
- Warp 删除有 20 秒确认，与 TPN 共用 `/yes`、`/no`；传送请求增加中央提醒和轻音效。
- 进服卡把“相伴时光”改为“在线时长”，加入线路、社群、文档和投喂入口，延续现有柔彩风格。
- Tips 默认每 90 秒一条，补充公共传送点提示。
- 新玩法 EXP 默认 0.85 倍，历史 EXP 和等级保留；[每日奖励](daily.md)与[挂机奖励](afk.md)显示实际数值。
- [商店](store.md)默认出售价格为购买价格的一半；每日出售件数按冒险用品 16、钻石器具 2、铁质器具 4、其他 100 计算。

本文对应 Momo Land 私服 NekoCore 1.5.0。更新包尚需由服主安排维护更新；线上是否已启用，以游戏界面和服主公告为准。
