# 商品价目表

普通商品默认 **109 种**。金额单位是游戏金币，以下按**每件**计价。

卖价为 `floor(买价 × 2/3)`；表格列的是 NekoCore 1.4.4 默认价，交易前看服内标价。

默认每种普通商品每天买一组、卖 200 件；回响碎片每天买 4 件。附魔书使用独立批次，见 [商店说明](store.md)。
