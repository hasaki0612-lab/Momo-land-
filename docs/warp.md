# 公共 Warp 与收藏

把适合分享的地方留给大家，也能收藏常去的好去处。

> [!NOTE]
> 当前线上版本为 **1.5.3**。本页现有 Warp、Home 与玩家传送规则已经可用；**1.6.0 待部署**。

## 浏览与前往

输入 **`/warp list`** 打开分类页。六个入口在中部排成两行：

| 左侧 | 中间 | 右侧 |
| --- | --- | --- |
| 收藏的传送点 | 生存一区 | 生存二区 |
| 下界 | 末地 | 玩法说明 |

选择世界或收藏，就能查看对应地点。也可以直接输入 `/warp list world`。

| 世界 | 指令中可用的世界名 |
| --- | --- |
| 生存一区 | `world` |
| 生存二区 | `world_new` |
| 下界 | `world_nether` |
| 末地 | `world_the_end` |

列表用创建者的玩家头显示传送点；把鼠标放上去查看名称、创建者、世界、坐标、群系和费用。每页最多 **12 个**，更多地点用翻页按钮查看。

世界列表和收藏页采用相同的整齐布局：上一页在左侧，页码居中，下一页在右侧，返回分类的入口靠近中间。只有一页时不会出现无效的翻页按钮。标题中的“Momo Land”和页面名称分开强调，周围保留空白，只用少量浅蓝装饰。

- **左键**：前往。
- **右键**：收藏或取消收藏。
- 收藏可以跨世界浏览；传送点被删除后也会从收藏中移除。

访问其他玩家的传送点需要 **60 金币**，访问自己的免费。安全检查或传送失败会取消收费；加载时请稍等，避免重复点击。

## 通过名称前往

输入 **`/warp warp <传送点名称>`**，通过公共传送点名称直接前往该地点。例如：

```text
/warp warp 樱花山顶
```

- 只有一个完全同名地点时，直接尝试传送。
- 有多个完全同名地点时，打开选择界面；根据创建者、世界、坐标和群系选择具体地点。每页最多 12 个，更多结果可以翻页。
- 没有完全匹配的地点时会提醒，不会替你选择名字相近的地点。

名称可以包含空格，首尾多余空格会忽略。使用与列表点击相同的收费和安全规则：自己的免费，访问其他玩家的地点 60 金币。

1.5.2 修复部分公共传送点在切换世界后可能无法正常使用的问题，完善跨世界传送时的目标区域加载与安全检查。若提示暂时加载失败，请稍后再试；若提示地点不安全，请创建者检查周围地形。

## 分享位置

站在想分享的位置，输入 **`/warp set <传送点名称>`**，例如：

```text
/warp set 樱花小屋
```

设置一次需要 **500 金币**。每人每个允许世界最多 **2 个**，四个世界合计最多 8 个。名称允许中文和空格，长度为 1～24 个字符；自己同一世界中的名称不能重复。

主城、大厅及其他世界属于保护区，不能设置，也不会扣费。脚下中心 **3×3** 要有完整、安全的落脚面，九个位置都需要足够的站立空间；液体、危险方块、细雪陷阱等不会通过。设置时和有人前往前都会检查，之后改坏地形也会暂时无法前往。

1.5.2 仍保留完整 3×3 要求；稳定的半砖、台阶、普通雪层、地毯和泥土小径不会仅因为高度不满一格而被拒绝，但九个位置都必须有足够支撑和站立空间。

创建者每天通过全部 Warp 合计最多获得 **900 金币**，按 **UTC+8 00:00** 开始新一天。达到上限后，访客仍支付 60 金币，创建者不再获得这笔收入。离线创建者也能收到上限内的收益。删除不退还设置费。

## 删除自己的传送点

在对应世界使用 **`/warp delete`**；也可以输入 **`/warp delete <世界>`**。

没有传送点时会提醒；有一个时直接询问确认；有两个时先打开选择页，核对名称、坐标、群系和创建时间后再选。

确认提示出现后，**20 秒内输入 `/yes`** 删除，输入 `/no` 取消。超时、退出或插件重载后需重新发起。正在使用中的传送点要等本次传送结束后再删除。
