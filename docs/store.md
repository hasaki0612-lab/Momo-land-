# 服务器商店

**`/store`** 打开普通商店。先选择分类，再选择商品和数量，最后确认交易。

## 怎么买卖

- **右键商品：买入。**
- **左键商品：出售。**

确认页会显示数量、总价和余额，检查好再确认。自定义数量按界面提示在聊天输入；取消时输入 `cancel`，不加斜杠。

余额不够、背包没空间或物品不足，交易不会按确认按钮硬做下去。遇到错误请保留聊天提示，不要连续重复确认。

---

## 分类与价格

植物与种子、食物、武器与装备、工具与杂物、红石机械、建筑材料、今日附魔书、冒险用品。

普通商品默认 109 种，包括钻石装备和工具，不出售下界合金装备。[完整默认价目表](prices.md)

卖价按**每件买价 × 2/3，向下取整**计算，再乘数量。例如买价 4 的商品，每件卖价是 2，出售 10 件得到 20。

## 每日额度

- 买入：每种普通商品每天默认最多**原版一组**。
- 出售：每种普通商品每天默认最多 **200 件**。
- 回响碎片的买入上限单独设置为 **4 件**。

按 **UTC+8 00:00** 重置。重登、重开商店不会刷新额度。

> [!NOTE]
> 出售物品必须和商品匹配。改名、附魔、磨损或其他额外数据可能导致不能回收；Bag、盔甲栏和副手里的物品不会被自动拿去卖。

---

## 今日附魔书

在 `/store` 选择“今日附魔书”。默认每天抽 **8 本**：2 本最高等级，6 本低阶书；不包含绑定诅咒和消失诅咒。

**换批时间是 UTC+8 04:00**，和普通商品午夜额度重置不同。

每人每本每批只能买一次，附魔书不回收。界面跨过换批时间时，重新打开再买。

| 书的类型 | 默认每本金币 |
| --- | ---: |
| 普通低阶书 | 300 |
| 一般最高等级书 | 1800 |
| 经验修补 | 3600 |
| 精准采集 | 2400 |
| 无限 | 2400 |
| 迅捷潜行 | 2700 |
| 风爆 | 3600 |

特定附魔按覆盖价计算，不再乘附魔等级。每天卖什么，以当期界面为准。
