# 服务器背包

**`/bag`** 打开 Bag。这是普通物品栏之外的额外收纳空间。

## 取放方式

- **左键**移动整叠。
- **右键**移动一件。

Bag 界面和玩家物品栏直接交换物品，注意聊天中的取放提示。

## 哪些地方可以用

| 所在世界 | 查看 | 取出 / 放入 |
| --- | --- | --- |
| `world` 生存一区 | 可以 | 可以 |
| `world_new` 生存二区 | 可以 | 可以 |
| `lobby` 大厅 | 可以 | 不可以 |

Bag 在两个生存区间共用，不会给每个世界各开一份。

## 格子解锁

| 等级 | 默认容量 |
| --- | ---: |
| Lv.1 | 18 格 |
| Lv.10 | 27 格 |
| Lv.25 | 36 格 |

达到过对应等级，格子就会永久解锁。

> [!NOTE]
> 取放报错时先停止重复点击，保留提示并联系服主。Bag 不是故障恢复或物品保险功能。
