# 玩家传送

> [!NOTE]
> 当前线上版本为 **1.5.1**；以下标注的 **1.5.2** 改善尚待部署，启用时间以服主公告为准。

## 发出请求

**`/tpn <玩家名>`**

请求传送到这位在线玩家身边。不是把对方拉到你的位置。

例如：

```text
/tpn Neko_Izumi
```

## 接受或拒绝

收到请求的玩家使用：

- **`/yes`**：接受，让对方过来。
- **`/no`**：拒绝本次请求。

收到请求时，保留聊天提示，并显示中央 Title 和一声轻提醒。只有接收者会收到这个提醒。

`/yes` 和 `/no` 也用于 [Warp 删除确认](warp.md)。已有确认或传送正在处理时，请先完成或取消当前操作；两个功能不会同时响应同一次确认。

默认请求有效期 **60 秒**。超时后需要重新申请。

---

## 落脚位置（1.5.2 待部署）

这一轮调整了玩家传送的安全判定。正常雪地、雪层、台阶、半砖、地毯、泥土小径、草地和普通自然地形，不再因为过于严格的检查而轻易拒绝传送；不需要专门搭建完整 3×3 平台。

目标仍以接受请求那一刻的位置为准。若当前位置不适合落脚，会尝试附近水平 2 格以内、垂直相差不超过 1.25 格的可站立位置，不会把玩家送到远处。

岩浆、明显火焰伤害、窒息、虚空、世界边界外和其他明显无法安全站立的位置仍会被阻止。目标区域暂时加载失败时会单独提醒；失败不会开始成功传送冷却。

## 冷却

| 最高已拥有头衔 | 默认成功传送冷却 |
| --- | ---: |
| 无 | 180 秒 |
| Yuki | 120 秒 |
| Momo | 60 秒 |
| Neko | 30 秒 |

成功传送才开始冷却；拒绝或超时不会按成功传送计。

> [!TIP]
> 接受前先站在安全地方。目标位置以接受请求时的位置为准，不会一直跟着你移动。
