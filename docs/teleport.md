# 玩家传送

## 发出请求

**`/tpn <玩家名>`**

请求传送到这位在线玩家身边。不是把对方拉到你的位置。

例如：

```text
/tpn Neko_Izumi
```

## 接受或拒绝

收到请求的玩家使用：

- **`/yes`**：接受，让对方过来。
- **`/no`**：拒绝本次请求。

默认请求有效期 **60 秒**。超时后需要重新申请。

---

## 冷却

| 最高已拥有头衔 | 默认成功传送冷却 |
| --- | ---: |
| 无 | 180 秒 |
| Yuki | 120 秒 |
| Momo | 60 秒 |
| Neko | 30 秒 |

成功传送才开始冷却；拒绝或超时不会按成功传送计。

> [!TIP]
> 接受前先站在安全地方。目标位置以接受请求时的位置为准，不会一直跟着你移动。
